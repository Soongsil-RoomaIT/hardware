# SAD v1.4 하드웨어 시연 가이드 (B)

기준: 2026-11-25 SAD v1.4 2.2·4.1·7.1·ADR-010/018/020·10.1, 연동 요청 B-1~4.
창문과 두 가전은 실제 기기가 아닌 **상태 LED**이며, 현관문만 모형 서보로 닫는다.
기존 공용 버튼 서보, DC 모터, CO₂/PM 센서 코드는 이전 구성의 참고용이다. 함께 연결하지 않는다.

## 1. 핀과 부품

BCM 번호와 물리 번호를 구분한다. 전원을 끈 상태에서 배선한다.

| 부품 | BCM | 물리 핀 | 연결 및 의미 |
|---|---:|---:|---|
| DHT11 DATA | 4 | 7 | VCC 3.3V, GND. 모듈에 풀업이 없으면 DATA↔3.3V 4.7~10kΩ |
| 창문 LED | 17 | 11 | GPIO→330Ω→LED 애노드, 캐소드→GND. 켜짐=OPEN |
| 공기청정기 LED | 22 | 15 | 위와 동일. 켜짐=ON |
| 제습기 LED | 27 | 13 | 위와 동일. 켜짐=ON |
| MC-38 접점 | 23 | 16 | 두 선을 GPIO23과 GND에 연결. 내부 풀업 사용, LOW=닫힘 |
| MQ-2 DO | 25 | 22 | 5V DO를 검증된 레벨 변환 회로를 거쳐 3.3V 이하로 연결 |
| 현관문 서보 신호 | 13 | 33 | 신호만 Pi GPIO. 별도 정격 5V 전원과 GND 공통 |
| 센서용 3.3V | — | 1 또는 17 | DHT11 모듈 전원 사양 확인 |
| Pi GND | — | 6 등 | 센서 및 외부 전원 GND 공통 |

GPIO17/22/27은 기존 팀원의 LED 핀을 그대로 유지했다. GPIO23·13·4도 기존 핀 유지.
GPIO25는 기존 핀과 겹치지 않는 **제안 핀**이며 A 담당에게 공유할 것. 확장 보드 실물 표기를 확인한다.
기존 버튼 서보 GPIO18, 창문 터치센서 GPIO24, L298N 및 전체 센서 배선은 v1.4에서는 사용하지 않는다.

### MQ-2 연결 전 반드시 확인

- 실제 모듈의 VCC/GND/DO/AO 표기 및 데이터시트를 확인한다. 가열부가 있는 5V 모듈을 가정한다.
- AO는 연결하지 않는다. 가열부 전류가 크므로 충분한 정격의 별도 5V 전원을 사용하고 GND를 Pi와 공통으로 연결한다. 5V 양극을 Pi의 3.3V나 GPIO에 넣지 않는다.
- DO에는 적합한 5V→3.3V 로직 레벨 변환 회로 사용을 권장한다. 저항 분압을 쓸 경우 예를 들어 DO→10kΩ→분기점→15kΩ→GND(공칭 5V에서 3.0V, 1% 저항 권장), 분기점만 GPIO25에 연결한다. 모듈의 오픈컬렉터/풀업 구조에 따라 출력 전압이 달라질 수 있다.
- Pi에 연결하기 전에 멀티미터로 분기점의 HIGH/LOW가 해당 Pi의 입력 기준을 만족하고, 최악의 공급전압에서도 3.3V를 넘지 않는지 확인한다. 확인하지 못하면 연결하지 않는다. DO 원선을 직접 연결하지 않는다.
- 실제 모듈의 검출 극성을 확인한다. 기본 active_low=True는 감지 시 LOW라는 가정이다. 반대면 설정을 바꾼다.
- 소프트웨어 기본 예열 대기 180초는 시연용 초기 설정일 뿐이다. 실제 모듈 제조사 지정 초기 컨디셔닝 및 매회 예열 시간을 준수하고, 안정된 뒤 감도를 설정한다. 예열 중에는 `None`이다.
- MQ-2는 농도 측정기·인증 가스경보기가 아니다. 단선/출력 고착도 항상 감지할 수 있는 것은 아니다. 실제 가스 누출이나 화재 예방 장치로 사용하지 않는다.

### MC-38 및 모형 조립

1. MC-38을 연결하기 전에 멀티미터 연속성으로 자석을 댔을 때 접점이 닫히고 떼면 열리는 모델인지 확인한다. 전원은 필요하지 않다.
2. 스위치와 자석을 고정 문틀/움직이는 문에 각각 설치하고 닫힌 위치에서 자석이 안정적으로 접점을 닫는지 확인한다. 선이 끊겨도 열린 것으로 읽힐 수 있으므로 배선을 함께 점검한다.
3. 폼보드/MDF 모형에 서보를 장착한다. 기구와 분리한 상태에서 각도·회전 방향부터 확인한다. 손가락 끼임 방지, 저토크 모형, 별도 퓨즈/전원 차단 장치를 확보한다.
4. 닫힌 문을 억지로 밀거나 걸림 상태에서 계속 밀지 않도록 기구·서보 각도와 동작시간을 조정한다. 기본 rest=-60°, push=60°, hold=1초, return=0.8초는 **초기값**이며 실제 모형에서 교정한다. 장애물 안전은 코드만으로 보장되지 않는다.
5. MC-38이 실제 문 상태와 일치한 뒤에만 `door_verified=True`로 설정한다. 현관문 원격 열기는 지원하지 않는다.

## 2. 설치와 단독 확인 (라즈베리파이)

기존 Edge Agent 서비스를 먼저 중지하여 GPIO를 동시에 점유하지 않게 한다.

```bash
cd hardware
python3 -m venv --system-site-packages .venv
source .venv/bin/activate
python -m pip install -e '.[hardware]'
# LED만 반복 시험. 출력 상태와 실제 점등을 눈으로 대조한다.
python examples/demo_v14.py led --cycles 50
# MC-38 raw 상태와 DHT11, MQ-2를 관찰. 서보는 움직이지 않는다.
python examples/demo_v14.py monitor
# MC-38 극성 및 설치 검증 후 문 상태를 해석한다.
python examples/demo_v14.py monitor --door-verified
# 모형 교정·안전 확인 이후에만 수동 닫기 1회
python examples/demo_v14.py door --door-verified --bench-confirmed --rest-angle=-60 --push-angle=60 --hold 1
```

예열 시간은 `--warmup`으로 실제 모듈 요건에 맞춰 변경한다. `--gas-active-high`는 실측 극성이 반대일 때만 사용한다. DHT/MQ-2 없이 LED 시험 가능. monitor는 두 환경 센서의 준비가 필요하다.
MQ-2 감지/해제는 우선 가짜 입력으로 SW 시험하고, 현물 시험은 담당자 감독 아래 제조사 지침의 승인된 시험 절차로 한다. 가스 직접 분사, 화염, 뜨거운 센서에 가연성 물질을 접촉시키는 시험 금지. 문서의 알코올 솜 예시는 가열부·전기 접점에서의 인화 위험을 별도로 평가한 뒤 승인된 조건에서만 실시한다.
