## 합리적으로 정한 부분과 확인이 필요한 부분

- 문서의 “최근 10분간 현관문이 열려있었다면”은 단독 실습에서 **연속 600초 열림**으로 해석했습니다.
  잠깐 열렸다가 닫힌 문을 나중에 다시 미는 동작은 하지 않습니다. 최종 정책은 C/A 합의가 필요합니다.
- 유스케이스에는 동작 전 사용자 승인이 있습니다. 드라이버 호출 자체가 승인을 대신하지 않습니다.
  오프라인 시 무승인 제어 허용 범위는 A/C에서 정해야 합니다.
- 사용자가 가진 온습도 모듈은 앞선 사진 기준 DHT11로 가정했습니다. DHT22면 실행 옵션을 바꿉니다.
- 사용자 요청대로 창문 감지에 터치를 지원하지만, 정전식 센서를 위치 스위치로 보증하지 않습니다.
  `verified=False`가 기본이며 현물 지속감지 시험 후에만 상태로 사용합니다.
- 기존 저장소의 장치 모델을 지원 대상으로 유지했습니다. SAD에 특정 센서 모델은 지정되어 있지 않습니다.
- 창문 `unknown`과 `closed`는 다릅니다. 기존 bool만 가진 Edge/UI는 상세 상태를 추가해야 합니다.
- 제습기는 요구사항에 있으나 기존 Edge 기본 장치 목록에는 없습니다. B 드라이버는 제공하며
  A/C/E가 장치 등록·제어 정책·UI를 연결해야 합니다.
- 센서가 없는 상태에서 CO₂/PM을 추정값이나 0으로 대신 보내지 않습니다.

## 완료의 의미

소프트웨어와 설계 문서, 모의시험은 저장소에서 검토할 수 있습니다.
실제 부품 구매·기구 제작·장비 구동·엔드투엔드 성능 검증은 장비를 연결한 환경에서 수행해야 합니다.
