# B 인수시험 및 실제 장비 기록

## 1. PC 자동 시험

```bash
python -m pip install -e '.[dev]'
python -m pytest -q
python -m ruff check roomcare_hw examples tests
python -m ruff format --check roomcare_hw examples tests
python examples/simulate_hardware.py
```

pytest는 gpiozero MockFactory 및 가짜 UART/센서를 사용합니다.
실제 GPIO·전원·끼임 방지·물리적 닫힘·센서 정확도를 검증한 결과가 아닙니다.
SCD41/PMS7003 제조사 통신 규격의 실제 응답은 별도 현물 시험이 필요합니다.

시험 범위: PMS 헤더/길이/체크섬/오류 프레임/부분 수신·전체 deadline,
DHT 재시도·null·cache timestamp, CO₂ 예열/만료/초기화 실패 정리,
비블로킹 수집·오류 복구, 터치 polarity/unknown,
창문 끝점·반복 명령·역방향 대기·타임아웃 latch·상충 리밋·장애물,
서보 직렬화·상태 불명·종료 중 취소·피드백 실패,
문 열기 거부·닫기 중복 방지·600초 기본 정책·재시도·정지.

| HW-04 | SCD41 예열·값 비교 | 초기 값 대기 정상, 기준 CO₂계와 비교/교정, 분리 시 오류 | 미실시 |

| HW-14 | Pi 강제 종료/전원 장애 | 소프트웨어와 독립적인 전원 차단/리밋 보호 확인 | 미실시 |

| INT-02 | 웹 명령→구동 시작 | 입력/모터 시작 시각 비교 5초 이내 | 미실시·A/C/E |
| INT-03 | 네트워크 단절→오프라인 | 단절 시작부터 10초 이내, 복구 이벤트 수신 | 미실시·A/C/D |

온습도/CO₂/PM 정확도의 허용 편차는 최종 부품 데이터시트 및 기준 측정기의 오차에 따라 확정합니다.
실측 없는 수치를 합격 기준으로 꾸며 넣지 않습니다.

## 3. 장비·기구 교정 기록

- 가전 수동 조작 시 상태 동기화 방법:
- 리밋 위치 / 장애물 검출 / 비상정지 / 수동 해제:
- 실물 배선 사진 / 측정 로그 위치:
